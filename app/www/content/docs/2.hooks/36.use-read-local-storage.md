## Installation

::code-group{sync="pm"}

```bash [npm]
npx sse-hooks add use-read-local-storage
```

```bash [yarn]
yarn dlx sse-hooks add use-read-local-storage
```

```bash [pnpm]
pnpm dlx sse-hooks add use-read-local-storage
```

```bash [deno]
deno run -A npm:sse-hooks add use-read-local-storage
```

```bash [bun]
bunx sse-hooks add use-read-local-storage
```

::

## Usage

```tsx [example.ts]
import { useReadLocalStorage } from "./{hooks file}";

const storedData = useReadLocalStorage("myKey");
// Access the stored data from local storage.
```
