## Installation

::code-group{sync="pm"}

```bash [npm]
npx sse-hooks add use-indexed-db
```

```bash [yarn]
yarn dlx sse-hooks add use-indexed-db
```

```bash [pnpm]
pnpm dlx sse-hooks add use-indexed-db
```

```bash [deno]
deno run -A npm:sse-hooks add use-indexed-db
```

```bash [bun]
bunx sse-hooks add use-indexed-db
```

::
