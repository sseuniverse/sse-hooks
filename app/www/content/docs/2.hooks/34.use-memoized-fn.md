---
title: useMemoizedFn
description: "A hook that returns a memoized version of a function.
  Unlike `useCallback`, the function identity remains stable across re-renders,
  but it always has access to the latest props and state without needing a dependency array.
  This is particularly useful for passing callbacks to optimized child components
  to prevent unnecessary re-renders while avoiding closure staleness."
category: utilities
links:

## Installation

::code-group{sync="pm"}

```bash [npm]
npx sse-hooks add use-memoized-fn
```

```bash [yarn]
yarn dlx sse-hooks add use-memoized-fn
```

```bash [pnpm]
pnpm dlx sse-hooks add use-memoized-fn
```

```bash [deno]
deno run -A npm:sse-hooks add use-memoized-fn
```

```bash [bun]
bunx sse-hooks add use-memoized-fn
```
