## Installation

::code-group{sync="pm"}

```bash [npm]
npx sse-hooks add use-copy-to-clipboard
```

```bash [yarn]
yarn dlx sse-hooks add use-copy-to-clipboard
```

```bash [pnpm]
pnpm dlx sse-hooks add use-copy-to-clipboard
```

```bash [deno]
deno run -A npm:sse-hooks add use-copy-to-clipboard
```

```bash [bun]
bunx sse-hooks add use-copy-to-clipboard
```
