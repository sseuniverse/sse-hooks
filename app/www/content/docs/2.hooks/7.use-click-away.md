## Installation

::code-group{sync="pm"}

```bash [npm]
npx sse-hooks add use-click-away
```

```bash [yarn]
yarn dlx sse-hooks add use-click-away
```

```bash [pnpm]
pnpm dlx sse-hooks add use-click-away
```

```bash [deno]
deno run -A npm:sse-hooks add use-click-away
```

```bash [bun]
bunx sse-hooks add use-click-away
```
