## Installation

::code-group{sync="pm"}

```bash [npm]
npx sse-hooks add use-portal
```

```bash [yarn]
yarn dlx sse-hooks add use-portal
```

```bash [pnpm]
pnpm dlx sse-hooks add use-portal
```

```bash [deno]
deno run -A npm:sse-hooks add use-portal
```

```bash [bun]
bunx sse-hooks add use-portal
```
