## Installation

::code-group{sync="pm"}

```bash [npm]
npx sse-hooks add use-media-quality
```

```bash [yarn]
yarn dlx sse-hooks add use-media-quality
```

```bash [pnpm]
pnpm dlx sse-hooks add use-media-quality
```

```bash [deno]
deno run -A npm:sse-hooks add use-media-quality
```

```bash [bun]
bunx sse-hooks add use-media-quality
```
