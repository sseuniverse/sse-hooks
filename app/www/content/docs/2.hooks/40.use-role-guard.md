## Installation

::code-group{sync="pm"}

```bash [npm]
npx sse-hooks add use-role-guard
```

```bash [yarn]
yarn dlx sse-hooks add use-role-guard
```

```bash [pnpm]
pnpm dlx sse-hooks add use-role-guard
```

```bash [deno]
deno run -A npm:sse-hooks add use-role-guard
```

```bash [bun]
bunx sse-hooks add use-role-guard
```
