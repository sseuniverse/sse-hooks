## Installation

::code-group{sync="pm"}

```bash [npm]
npx sse-hooks add use-key
```

```bash [yarn]
yarn dlx sse-hooks add use-key
```

```bash [pnpm]
pnpm dlx sse-hooks add use-key
```

```bash [deno]
deno run -A npm:sse-hooks add use-key
```

```bash [bun]
bunx sse-hooks add use-key
```
