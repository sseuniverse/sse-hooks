## Installation

::code-group{sync="pm"}

```bash [npm]
npx sse-hooks add use-user-media
```

```bash [yarn]
yarn dlx sse-hooks add use-user-media
```

```bash [pnpm]
pnpm dlx sse-hooks add use-user-media
```

```bash [deno]
deno run -A npm:sse-hooks add use-user-media
```

```bash [bun]
bunx sse-hooks add use-user-media
```
