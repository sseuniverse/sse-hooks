## Installation

::code-group{sync="pm"}

```bash [npm]
npx sse-hooks add use-kbd
```

```bash [yarn]
yarn dlx sse-hooks add use-kbd
```

```bash [pnpm]
pnpm dlx sse-hooks add use-kbd
```

```bash [deno]
deno run -A npm:sse-hooks add use-kbd
```

```bash [bun]
bunx sse-hooks add use-kbd
```

::
