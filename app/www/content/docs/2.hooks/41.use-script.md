## Installation

::code-group{sync="pm"}

```bash [npm]
npx sse-hooks add use-script
```

```bash [yarn]
yarn dlx sse-hooks add use-script
```

```bash [pnpm]
pnpm dlx sse-hooks add use-script
```

```bash [deno]
deno run -A npm:sse-hooks add use-script
```

```bash [bun]
bunx sse-hooks add use-script
```

::
