## Installation

::code-group{sync="pm"}

```bash [npm]
npx sse-hooks add use-screen-share
```

```bash [yarn]
yarn dlx sse-hooks add use-screen-share
```

```bash [pnpm]
pnpm dlx sse-hooks add use-screen-share
```

```bash [deno]
deno run -A npm:sse-hooks add use-screen-share
```

```bash [bun]
bunx sse-hooks add use-screen-share
```

::
